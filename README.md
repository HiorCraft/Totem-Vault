## 📖 About
 
**CC-Community-Totem** is a Minecraft resource pack that replaces the default Totem of Undying with custom, individually designed textures. Each texture is assigned to a specific Creator or Community Member, allowing players to use unique, personalized totems in-game.
 
Whether you're a fan of a Creator or simply want to show some love to a Community Member — Totem Vault has a totem for you.
 
---
 
## ✨ Features
 
- 🎨 **Custom Totem Textures** — Unique designs for each Creator and Community Member
- 👤 **Personalized** — Every totem is tied to a specific person
- 🔧 **Easy to use** — Simple drag-and-drop installation
- 🕹️ **Compatible** — Supports Minecraft Java Edition 1.21.4 – 1.21.x

## 📥 Installation
 
1. Download the latest release from [Modrinth](https://modrinth.com/resourcepack/cc-community-totem) or the [Releases](https://github.com/HiorCraft/CC-Community-Totem/releases) page.
2. Move the `.zip` file into your Minecraft resource packs folder:
   - **Windows:** `%appdata%\.minecraft\resourcepacks\`
   - **macOS:** `~/Library/Application Support/minecraft/resourcepacks/`
   - **Linux:** `~/.minecraft/resourcepacks/`
3. Launch Minecraft and go to **Options → Resource Packs**.
4. Enable **Totem Vault** and enjoy your custom totems!
